# HeOCR Android: design files

The Bounding Box brand applied to the Android app: screens, stylesheets, icons, launcher icon, splash, fonts and store graphics. Prepared 2026-11-19 against `HeOCR/heocr-desktop` at `1d012b2` (app 0.1.0).

Start with [`SPEC.md`](SPEC.md). To see the screens, open [`mockups/index.html`](mockups/index.html) in a narrow browser window, or look in `mockups/png/`.

Nothing in this folder is app code, and nothing here loads anything from the network.

## Index

| Path | What it is |
|---|---|
| `overview.png` | One board with the main screens, the launcher icon options, the splash and the store graphics. |
| `SPEC.md` | The specification: the WebView recommendation and why, what the app must provide, tokens, every component with sizes and states, the screen flow, motion, right-to-left rules, accessibility, the brand extensions and the open questions. |
| `css/tokens.css` | Brand tokens for light and night, plus the app's extensions. Night follows `prefers-color-scheme`. |
| `css/result.css` | **Drop-in stylesheet for the result view.** Styles the HTML that `view.py` builds today, unchanged. |
| `css/app.css` | The stylesheet for whole screens in the WebView. |
| `css/fonts.css`, `css/fonts-embedded.css` | The five font faces, by file reference and as data URIs. |
| `css/result-standalone.css`, `css/app-standalone.css` | One-file builds with tokens and fonts inside, for a page filled with `set_content`. Generated by `tools/make_standalone.py`. |
| `fonts/` | Noto Sans Hebrew 400, 500, 700 and JetBrains Mono 500, 700 as subset WOFF2 (51 KB together), both OFL texts, and `subset_fonts.py`, which rebuilds them. |
| `icons/in-app/` | 20 icons as SVG on a 24 dp grid, `icons.json` (which ones mirror in Hebrew) and `preview.png`. |
| `launcher/` | Launcher icon: SVG sources, Android resources (`res/`: adaptive icon XML, VectorDrawable foreground and monochrome layers, background colour, legacy PNGs), Play Store icon 512, the same PNGs under Briefcase's file names (`briefcase/`), and `preview-masks.png`. |
| `launcher/alternate-blue/` | The same set on a blue ground, for the owner to choose between. |
| `splash/` | Splash icon for light and night (SVG, VectorDrawable, PNG), window background colours, Briefcase-named square images, previews. |
| `mockups/he/`, `mockups/en/` | Every screen as a static page built on the stylesheets above. No script. Click-through: each link goes to the next screen and carries the app action in `data-action`. |
| `mockups/png/412x915/`, `mockups/png/360x800/` | Renders of every screen at both sizes, `light/` and `night/`, `he/` and `en/`, at 2× pixel density. |
| `mockups/png/full-length/` | The whole result page and the whole About page. |
| `mockups/png/font-scale-200/` | Six screens per language at 200% text size. |
| `strings/strings.json` | Every string in the mockups, Hebrew and English, with the keys that reuse already-reviewed wording marked. |
| `store/` | Store graphics staged in the fastlane layout, with notes. See [`store/README.md`](store/README.md). |
| `tools/` | The scripts that produced the mockups, icons, launcher, splash and store files. Reference only. |

## Source of every asset

Everything is original work made for HeOCR or derived from the HeOCR brand files, except the two typefaces.

| Asset | Source | Licence |
|---|---|---|
| Colour, type and shape tokens | The brand handover (`tokens/tokens.json`), unchanged. App extensions are new and listed in `SPEC.md` §5 and §16. | Project's own |
| The mark (ה in a box with four handles) | Logo 1 from the brand handover (`logo/svg/mark.svg`). The launcher's heavier "icon weight" and the monochrome layer are redrawn from the same geometry. | Project's own |
| Launcher icon, splash icon, all their PNGs and XML | Drawn for this handover from the mark; PNGs rasterised from the SVGs in `launcher/**/svg/` and `splash/svg/`. | Project's own |
| In-app icons (20) | Drawn for this handover. Not taken from Material Symbols or any other icon set. | Project's own |
| Noto Sans Hebrew | `google/fonts`, `ofl/notosanshebrew/NotoSansHebrew[wdth,wght].ttf`, instanced to three weights and subset by `fonts/subset_fonts.py`. | SIL OFL 1.1 (`fonts/OFL-NotoSansHebrew.txt`) |
| JetBrains Mono | `google/fonts`, `ofl/jetbrainsmono/JetBrainsMono[wght].ttf`, instanced to two weights and subset by the same script. | SIL OFL 1.1 (`fonts/OFL-JetBrainsMono.txt`) |
| Mockup pages and stylesheets | Written for this handover. | Project's own |
| Text in the mockups and store screenshots | Invented: a neighbourhood library's winter notice. No real document, person or company. | Project's own |
| Interface strings | Reused from `heocr_mobile/app.py` and `heocr_desktop/i18n.py` where they existed; the rest written for this handover (`strings/strings.json`). | Project's own |
| Store feature graphics and phone screenshots | Composed from the mockup renders and the mark. | Project's own |

When the fonts are bundled in the app, add both to `THIRD_PARTY_LICENSES.md` and ship the two OFL texts.

## Not covered

- App code: `src/`, the workflows and `pyproject.toml` are untouched. The implementation is heocr-app's.
- The desktop app's icons, which still show the old aleph.
- The VectorDrawable XML was written by hand and has not been compiled; check it in a build.
